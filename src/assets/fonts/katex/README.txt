These unmodified WOFF2 faces come from KaTeX 0.16.22:
https://registry.npmjs.org/katex/-/katex-0.16.22.tgz

KaTeX_Caligraphic-Regular provides TeX mathcal capitals (S, C, A, O, L, F, M, E).
KaTeX_Main-Regular provides upright Greek letters and mathematical punctuation.
KaTeX_Math-Italic provides mathematical italic variables such as theta.
